# Original generated particle artwork

Generated with the built-in imagegen tool. These are original educational illustrations, not photographs of measured samples. No third-party stock photography was used. Nanoplastic imagery is conceptual; it is not an optical micrograph or scale reference. No claim of exclusive copyright or guaranteed legal status is made.

Three independently composited transparent foreground assets: microbead.webp, tire-wear.webp, nano-aggregate.webp. The water-background.webp plate stays stationary. WebP exports preserve alpha and are resized for web delivery. Existing original fiber and fragment cutouts are reused where appropriate. Jev advised the text-to-asset category mapping; visual inspection and implementation were done by Codex.
